# 一人回し（PC用・自分専用）

AI相手に対戦できるカードゲームの一人回しツールです。サーバー不要で、`index.html` をブラウザ（Chrome / Edge）で開くだけで動きます。どこにも公開しません。

## 起動

1. このフォルダをPCに置く（GitHubの「Code → Download ZIP」で取得して展開）
2. `index.html` をダブルクリック

カード・デッキ・画像はそのPCのブラウザ内（localStorage / IndexedDB）にだけ保存されます。ときどき「カード」タブの **バックアップを保存** でJSONに書き出してください。

## できること

- **カード登録**：名前・文明・コスト・パワー・テキスト・画像。テキストを貼ると自動処理できる能力を読み取り、読めない文は「手動」と表示
- **画像の差し替え**：カードごとにファイル／URL／ドロップで設定。「画像をまとめて読み込む」で **ファイル名＝カード名** の画像を一括割り当て
- **デッキ**：`4 カード名` 形式のリストで作成。枚数・文明・S・トリガー数・未登録カードをチェック
- **対戦**：AIと対戦／一人回し（両方自分で操作）／AI同士の観戦
  - 自動：アンタップ・ドロー、マナ支払い（文明込み）、召喚酔い、攻撃・バトル、ブロック、シールドブレイク、S・トリガー、勝敗判定
  - キーワード：ブロッカー、スピードアタッカー、W/T/Q/ワールド・ブレイカー、パワーアタッカー、スレイヤー、S・トリガー、マッハファイター、ブロックされない など
  - 効果文：出た時／攻撃する時／破壊された時／ターンのはじめ／呪文 の ドロー・マナ加速・シールド追加・破壊・バウンス・タップ・ハンデス・回収・ブレイク・パワー＋
  - 自動化できない効果は **右クリック** で好きなゾーンに動かして処理

同梱のサンプルカードは動作確認用のオリジナルです。実際のカードは自分で登録してください（JSONでまとめて読み込みも可）。

種類は クリーチャー／呪文／タマシード／城 に対応。ツインパクトは「ツインパクト（呪文側）」欄に呪文側を登録すると、手札から「呪文側を使う」を選べます。城は使うと表向きのシールドとして置かれ、ブレイクされると墓地へ行きます。

`private/` フォルダはgitに含めません（自分のカード画像入りデータ置き場）。

### カードJSONの形式（まとめて読み込み用）

```json
[
  { "name": "カード名", "civs": ["火"], "cost": 3, "type": "クリーチャー", "power": 3000, "races": ["種族"], "text": "スピードアタッカー", "imageUrl": "" }
]
```

## 公式カードページから取り込む

1. 「カード」タブの「DM取り込み」ボタンを、ブラウザのブックマークバーへドラッグして登録する（最初の1回だけ）
2. 公式のカード詳細ページURL（`https://dm.takaratomy.co.jp/card/detail/?id=…`）を貼って「公式ページを開く」
3. 開いた公式ページで、ブックマークの「DM取り込み」を押す → 画像・テキスト・フレーバー・種族などが自動で入る

**まとめて取り込む**
- 検索結果の一覧ページでブックマークを押す → 全ページをめくって取り込むか、表示中のページだけ取り込むかを選べる
- 「パック単位で取り込む」にパックの記号（例: `dm26ex4`）を入れて押す → 開いたページでブックマークを押すと、そのパックのカードを番号順に全部取り込み
- 取り込み済みのカードは飛ばせます（毎回確認が出ます。キャンセルで全部取り込み直し）

うまく送れない時は、コピーされたデータを「貼り付けて追加」に貼ります。公式ページの内容を読むのはあなたのブラウザで、データはこのPCの中だけに保存されます。

```bash
node test/sim.js 300   # AI同士で300戦して例外がないか確認
```

## 友人と対戦（トンネルを使う）

自分のPCで小さな中継サーバーを動かし、トンネルで友人に入ってもらいます。サーバーは操作と選択を相手に送るだけで、対戦の処理は両方のブラウザで同じように進みます（同じ乱数を使うので、盤面は両者で一致します）。

1. サーバーを起動（Node.js だけで動きます。追加インストールなし）
   ```
   node server/online-server.js
   ```
2. 別のウィンドウでトンネルを開く（例：cloudflared）
   ```
   cloudflared tunnel --url http://localhost:8787
   ```
   表示された `https://xxxx.trycloudflare.com` を控える
3. いつもの画面（index.html）で、モードを **友人と対戦（部屋を作る）** にして「対戦開始」
   - サーバー欄は `http://localhost:8787` のままでOK
   - 部屋の番号が出るので、友人に `https://xxxx.trycloudflare.com/?join=部屋番号` を送る
4. 友人がそのURLを開いて「参加する」を押すと始まります
   - 友人のデッキは、ホストの「AIのデッキ」で選んだもの（友人がそのURLの画面でバックアップを読み込んでいれば、自分のデッキも選べます）

- 相手の手札・山札・シールドの中身は見えません。「戻す」は使えません
- 盤面がずれたときはログに「⚠ 相手と盤面がずれている可能性」と出ます（両者が同じ版の画面を使っているか確認してください）
- `private/` と `.git` はサーバーから配信しません

## スマホで遊ぶ

画面の幅が狭いと、自動でスマホ用の配置になります（上が相手、下が自分、手札は一番下を横にスクロール）。

- カードを **長押し** で大きく表示。そこから「手動の操作」もできます
- 「ログ」でログを横から出す、「⋯」でループ記録などのボタンを出す
- スマホで開くには、PCで `node server/online-server.js` を起動して、同じWi-Fiのスマホから `http://PCのIPアドレス:8787` を開きます（外からならトンネルのURL）。
  カードやデッキはブラウザごと・URLごとに保存されるので、スマホの画面で一度「カード」タブからバックアップを読み込んでください（トンネルのURLは毎回変わるので、家ではIPアドレスのほうが便利です）

## Ollama（言語AI）と対戦

自分のPCの Ollama に手を選ばせるモードです。ルールと盤面の処理はこのツールが行い、言語AIには「今できる手」を番号つきで見せて選ばせるだけなので、ルール違反や数え間違いは起きません。言語AIに見せるのは、そのプレイヤーに見えている情報だけです（相手の手札・シールドの中身は見せません）。

1. Ollama を起動し、モデルを入れておく（例: `ollama pull qwen2.5:7b`）
2. モードで **Ollama（言語AI）と対戦** を選ぶ
3. 「接続を確かめる」を押すと、入っているモデルが出るので選ぶ
4. 必要なら「作戦メモ」にAIのデッキの回し方を書く（例：「サガを出してループする」）
5. 対戦開始。AIの判断の理由はログに「🤖」で出ます

- 言語AIの答えがおかしい・時間切れ（90秒）・つながらない時は、いつものAIが代わりに選びます
- 「つながりません」と出る時は、Ollama をブラウザから呼べるように、環境変数 `OLLAMA_ORIGINS=*` を設定して Ollama を起動し直してください
- 大きいモデルほど賢くなりますが、1手ごとの時間が長くなります

### デッキの回し方と基礎ルール（AIに渡すプロンプト）

- `strategies/_基礎ルール.md`：AIに毎回渡す基礎ルール
- `strategies/デッキ名.md`：デッキごとの回し方（ファイル名をデッキ名と同じにする）
- mdを書き換えたら、`node tools/build-strategies.js` で `js/strategies.js` を作り直す（画面はこのjsを読む）
- 画面の「デッキ」タブの「AIの回し方」に書けば、そちらが優先されます（バックアップにも入ります）。空なら同じ名前の既定の回し方を使います
- Ollamaと対戦する時は、AIのデッキの回し方が自動で「作戦メモ」に入ります（その場で書きかえてもOK）
